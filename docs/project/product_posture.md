# Product posture

Alpha: private capture/history, offline HTML/SVG maps, comparison, blocked restart/migration
proposals and experimental bounded same-workspace column reorder. No public registry release.

Synthetic tests do not prove real layout mutation or application recovery. Read-only observation
and a correct map do not unfreeze a terminal or preserve unsaved application state. Unsupported
restoration remains blocked. See [usage and safety](../usage.md).
